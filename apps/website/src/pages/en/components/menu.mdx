## Overview

A `Menu` (dropdown) presents a list of **actions** triggered by a button — Edit, Duplicate, Delete.
For choosing a persistent value from a list, use <a href={withBase('/components/select/')}>Select</a>
instead.

## Anatomy

A `<button>` trigger (`aria-haspopup="menu"`) opens a floating `role="menu"` of `role="menuitem"`s.
Both the trigger and the panel are sketchy boxes (`@ghds/sketch-core`). Data-driven — pass an
`items` array of `{ value, label, disabled?, href? }` (`href` is React / Web Components only — React
Native has no link items).

An item with an `href` renders as a real link — a `role="none"` wrapper around
`<a role="menuitem" href>` — so an action that links out (e.g. "View source on GitHub") keeps native
link behaviour: open in new tab, copy link address, crawlability. Activating it navigates natively and
closes the menu; `onSelect` / `select` is not fired for href items. A `disabled` href item drops its
`href`; an empty `href` (`''`) counts as no `href`, so the item stays a plain action. Menu stays an **action** menu — for a dropdown of site-navigation links use
<a href={withBase('/components/nav-menu/')}>NavMenu</a> (`gh-nav-menu`), which has no menu roles, and for a
whole navigation bar use `NavigationMenu` / `gh-navigation-menu`.

## Accessibility

- **React / Web Components**: `aria-haspopup="menu"` + `aria-expanded` trigger; `role="menu"` panel of
  `role="menuitem"`s. Enter/Space/ArrowDown open and focus the first item; Arrow/Home/End move focus;
  Enter/Space activate (on an href item Enter is left to the native link and Space clicks it, so it
  navigates without `preventDefault`); Escape closes and restores focus to the trigger; click-outside closes. Web
  Components dispatches a `select` event for action items.
- **React Native**: a `Modal`-anchored panel; selection by tap. `accessibilityRole="menu"`/`"menuitem"`.
  Arrow-key roving is web-only.
- See the <a href={withBase('/accessibility/')}>Accessibility Guide</a>.

## Code examples

```tsx
// React — @ghds/react
import { Menu } from '@ghds/react/menu';

<Menu
  label="Actions"
  items={[
    { value: 'edit', label: 'Edit' },
    { value: 'duplicate', label: 'Duplicate' },
    { value: 'archive', label: 'Archive', disabled: true },
    { value: 'delete', label: 'Delete' },
    // A real link: native navigation, no onSelect.
    { value: 'source', label: 'View source', href: 'https://github.com/org/repo' },
  ]}
  onSelect={(value) => run(value)}
/>;
```

```html
<!-- Web Components — @ghds/web-components -->
<script type="module">
  import '@ghds/web-components/menu';
  const menu = document.getElementById('actions');
  // items is a property, not an attribute
  menu.items = [
    { value: 'edit', label: 'Edit' },
    { value: 'delete', label: 'Delete' },
    { value: 'source', label: 'View source', href: 'https://github.com/org/repo' },
  ];
  menu.addEventListener('select', (e) => run(e.detail));
</script>
<gh-menu id="actions" label="Actions"></gh-menu>
```

```tsx
// React Native — @ghds/react-native
import { Menu } from '@ghds/react-native/menu';

<Menu
  label="Actions"
  items={[
    { value: 'edit', label: 'Edit' },
    { value: 'delete', label: 'Delete' },
  ]}
  onSelect={(value) => run(value)}
/>;
```
