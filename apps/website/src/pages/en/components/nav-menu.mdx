## Overview

A `NavMenu` groups related **pages** behind one header trigger — e.g. "Design" revealing Design Style,
Foundations, Design Principles and UX Writing. Every entry is a real link, so visitors keep native link
behaviour: open in new tab, copy link address, and crawlers can follow them.

It is the navigation counterpart of <a href={withBase('/components/menu/')}>Menu</a>. Menu is an
**action** menu (`role="menu"`, for commands like Edit / Delete); NavMenu is a **disclosure** of links and
deliberately uses no menu roles, which the ARIA Authoring Practices reserve for command sets. For a whole
navigation bar with several groups, `NavigationMenu` / `gh-navigation-menu` renders the full row.

## Anatomy

A `<button aria-expanded aria-controls>` trigger shows and hides a floating panel. The panel holds a plain
list — `<ul>` / `<li>` — of `<a href>` links. There is no `role="menu"`, `role="menuitem"` or
`aria-haspopup="menu"` anywhere. The trigger is a sketchy box (`@ghds/sketch-core`) and the panel reuses the
`comp.menu.*` tokens, so it looks like Menu. Data-driven — pass an `items` array of `{ href, label }`.

## Accessibility

- **React / Web Components**: disclosure pattern — the trigger has `aria-expanded` and `aria-controls`
  pointing at the panel. Links are in the natural Tab order (no roving `tabindex`). Arrow keys are an
  optional shortcut on top of Tab. Escape closes and returns focus to the trigger; clicking outside or
  tabbing out of the component closes it. Activating a link navigates natively.
- **Current page**: pass `current` (the page path) so the matching link carries `aria-current="page"` and
  screen readers announce it as the current page.
- **React Native**: no NavMenu — use `NavigationMenu` from `@ghds/react-native`.
- See the <a href={withBase('/accessibility/')}>Accessibility Guide</a>.

## Code examples

```tsx
// React — @ghds/react
import { NavMenu } from '@ghds/react/nav-menu';

<nav aria-label="Main">
  <NavMenu
    label="Design"
    items={[
      { href: '/design-style/', label: 'Design Style' },
      { href: '/foundations/', label: 'Foundations' },
      { href: '/principles/', label: 'Design Principles' },
      { href: '/ux-writing/', label: 'UX Writing' },
    ]}
  />
</nav>;
```

```html
<!-- Web Components — @ghds/web-components -->
<script type="module">
  import '@ghds/web-components/nav-menu';
  // items is a property, not an attribute
  document.getElementById('design').items = [
    { href: '/design-style/', label: 'Design Style' },
    { href: '/foundations/', label: 'Foundations' },
  ];
</script>
<nav aria-label="Main">
  <gh-nav-menu id="design" label="Design"></gh-nav-menu>
</nav>
```
