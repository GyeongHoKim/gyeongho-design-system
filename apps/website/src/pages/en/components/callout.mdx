## Overview

A `Callout` is a boxed aside that sets a note, a tip, or a caveat apart from the surrounding
long-form content — a docs page, a guide, a changelog. It is static: it is part of the content, not
a reaction to something the user did. For task or page status, use an
<a href={withBase('/components/alert/')}>Alert</a>; for transient feedback, use a
<a href={withBase('/components/toast/')}>Toast</a>.

## Anatomy

A sketchy box (`@ghds/sketch-core`) with a variant-coloured outline and icon, an optional bold
heading, and a body. There is no dismiss button.

## Accessibility

- **React and Web Components**: the root has `role="note"` — content that is parenthetical to the main
  content. It is never a live region (no `role="status"`/`"alert"`), so screen readers read it in
  document order instead of announcing it.
- The outline and icon use themed status accents (`sys.color.border.*` / `sys.color.icon.*`) that
  keep at least 3:1 against every surface in light and dark themes. The heading and body text meet
  4.5:1. The variant icon is decorative; put the meaning in the heading.
- React: pass `role` / `aria-label` to override the default role or name the aside.
- Web Components: set a `role` / `aria-label` attribute on `<gh-callout>` to override the default
  role (exposed through `ElementInternals`) or name the aside.
- See the <a href={withBase('/accessibility/')}>Accessibility Guide</a>.

## Content

An optional short heading plus one or two sentences. The body accepts rich content (links, inline
code, a short list).

## Code examples

```tsx
// React — @ghds/react
import { Callout } from '@ghds/react/callout';

<Callout variant="tip" heading="Recommended fonts">
  Load the web fonts with Fontsource in your app.
</Callout>;
```

```html
<!-- Web Components — @ghds/web-components -->
<script type="module">
  import '@ghds/web-components/callout';
</script>
<gh-callout variant="tip" heading="Recommended fonts">
  Load the web fonts with Fontsource in your app.
</gh-callout>
```
