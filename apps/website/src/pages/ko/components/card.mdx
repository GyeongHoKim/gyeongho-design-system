## 개요

`Card`는 관련 콘텐츠를 묶기 위한 범용 표면이에요 — 자체적으로 인터랙티브하지 않고 "이것들이 함께 속한다"는 의미 외에는 내장된 의미가 없어요. 웹에서는 카드 전체를 링크 하나로 만들 수도 있어요. [링크 카드](#link-cards)를 참고하세요.

## 구조

일반 자식 요소 뒤에 그려진 손그림 사각형 외곽선이에요. Web Components의 `gh-card`에는 슬롯이 두 개 있어요. 먼저 렌더링되는 이름 있는 `title` 슬롯과 본문용 기본 슬롯이에요. `title` 슬롯의 콘텐츠와 기본 슬롯의 `<h1>`/`<h2>`/`<h3>`는 제목 스타일(`::slotted` CSS)을 받아요. React와 React Native에는 동등한 제목 슬롯이 없어요 — 콘텐츠는 그냥 일반 자식 요소예요.

## 변형 및 상태

Button이나 Input과 달리 Card는 주로 **정적 컨테이너**예요 — 이 섹션은 존재하지 않는 상태를 억지로 끼워맞추지 않고 의도적으로 간결해요.

## 종이 변형

- React Native에는 아직 `interactive`와 링크 모드가 없어요.
- React의 `fill`과 Web Components/React Native의 `elevated`는 `plain`에만 적용돼요.
- React Native는 값을 Restyle 테마(`theme.card.*`)에서 읽으므로 커스텀 테마로 덮어쓸 수 있어요.

```tsx
// React
<Card variant="sticky" tone="warning" fastener="tape" tilt="left">
  <h3>Reminder</h3>
  <p>Water the plants.</p>
</Card>
```

### 종이 색 바꾸기

웹에서는 모든 값이 CSS 커스텀 프로퍼티예요. 카드를 감싸는 컨테이너에 설정하면 그 안의 종이 색이 바뀌어요. `:root`에는 설정하지 마세요. 다크 테마가 모든 `--comp-card-*` 프로퍼티를 다시 선언하기 때문에(`[data-theme]`, 그리고 OS 다크 모드에서는 `:root:not([data-theme])`) 그곳에서는 덮어쓴 값이 사라져요. 같은 이유로 컨테이너는 `data-theme`이 붙은 요소의 안쪽에 두세요.

```css
.notes {
  --comp-card-sticky-bg-warning: var(--sys-color-paper-info);
}
```

### 줄 있는 카드

줄 간격이 본문 줄 높이와 같아서 본문 글자가 줄 위에 놓여요. 이건 본문 텍스트에만 해당해요. 제목이나 요소의 여백(예: `<p>`의 기본 여백)이 있으면 그 아래 줄이 괘선에서 어긋나요. 줄 있는 카드에는 여백 없이 본문 텍스트를 넣고, `line-height`는 바꾸지 마세요.

{/* 데모 링크 카드가 두 언어에서 같은 #link-cards를 가리키도록 id를 고정해요. */}
<h2 id="link-cards">링크 카드</h2>

카드 전체를 링크 하나로 만들려면 Web Components에서는 `href`를, React에서는 `<a>` 자식과 함께 `asChild`를 쓰세요(Button의 `asChild`와 같은 방식이에요). 링크가 곧 카드 표면이라 감싸는 요소가 따로 없어요.

- 마우스를 올리면 `interactive`처럼 카드가 떠오르고, `plain` 카드의 스케치 외곽선이 진해져요(`comp.card.stroke.hover`).
- 키보드로 포커스하면 포커스 링(`comp.card.focus.ring`)이 보이고 카드가 떠올라요.
- 종이 변형, `tone`, `fastener`, `tilt`는 평소처럼 동작해요.

```tsx
// React
<Card asChild variant="sticky" tone="info">
  <a href="/docs/tokens">
    <h3>토큰</h3>
    <p>모든 플랫폼의 디자인 값.</p>
  </a>
</Card>
```

```html
<!-- Web Components -->
<gh-card href="/docs/tokens" variant="sticky" tone="info">
  <h3 slot="title">토큰</h3>
  <p>모든 플랫폼의 디자인 값.</p>
</gh-card>
```

링크 카드 안에는 버튼, 입력 필드, 다른 링크를 넣지 마세요. 인터랙티브 요소는 링크 안에 중첩할 수 없어요. 카드의 텍스트 콘텐츠가 링크의 접근 가능한 이름이 되니 짧게 유지하세요.

## 접근성

- **React**: 일반 `<div>`를 렌더해요. role이나 라벨이 자동으로 설정되지 않아요 — "어떤 ARIA role/랜드마크든 호출자가 설정해요"(컴포넌트의 문서 주석에 따름). `asChild`를 쓰면 자식 요소가 자신의 시맨틱(예: 링크)을 그대로 유지해요.
- **Web Components**: `label`이 제공되면 `gh-card`가 자동으로 `internals.role = 'group'`과 `internals.ariaLabel`을 설정해요 — React가 *복제하지 않는* 실제 동작이에요. `href`를 쓰면 호스트에는 role이 없고 내부 `<a>`가 링크가 돼요. 이때 `label`은 그 링크의 `aria-label`이 되어 텍스트 콘텐츠 대신 접근 가능한 이름으로 쓰여요.
- **React Native**: `accessibilityLabel`이 전달될 때만 `accessibilityRole="summary"`를 설정해요.
- 일반적인 관례는 <a href={withBase('/accessibility/')}>접근성 가이드</a>를 참고하세요.

## 콘텐츠

해당 없음 — 카드는 고정된 콘텐츠 모델이 없어요. 콘텐츠는 호출자가 자식(React/RN)이나 슬롯(Web Components)으로 전달하는 것이에요.

## 코드 예시

```tsx
// React — @ghds/react (`fill`은 있고 `elevated`는 없어요)
import { Card } from '@ghds/react/card';

<Card fill="hachure">
  <h3>Hachure</h3>
  <p>Sketched, translucent fill.</p>
</Card>;
```

```html
<!-- Web Components — @ghds/web-components (`elevated`와 `label`은 있고 `fill`은 없어요) -->
<script type="module">
  import '@ghds/web-components/card';
</script>
<gh-card label="Elevated" elevated>
  <h3 slot="title">Elevated</h3>
  <p>Drop-shadow sketch outline suggests elevation.</p>
</gh-card>
```

```tsx
// React Native — @ghds/react-native (`elevated`는 있고 `fill`은 없어요)
import { Card } from '@ghds/react-native/card';
import { Text } from '@ghds/react-native/theme';

<Card elevated accessibilityLabel="Summary">
  <Text>Elevated card content</Text>
</Card>;
```
