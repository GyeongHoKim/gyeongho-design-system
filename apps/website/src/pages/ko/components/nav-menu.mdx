## 개요

`NavMenu`는 관련된 **페이지**를 헤더의 트리거 하나 아래에 묶어요 — 예: "Design"을 누르면 Design Style,
Foundations, Design Principles, UX Writing이 나타나요. 모든 항목이 실제 링크라서 새 탭에서 열기, 링크 주소
복사 같은 기본 링크 동작이 그대로 유지되고, 크롤러도 링크를 따라갈 수 있어요.

<a href={withBase('/components/menu/')}>Menu</a>의 내비게이션 버전이에요. Menu는 **동작** 메뉴(`role="menu"`,
Edit / Delete 같은 명령)이고, NavMenu는 링크를 펼쳐 보여 주는 **디스클로저**예요. ARIA Authoring Practices는
메뉴 역할을 명령 모음에만 쓰도록 하므로, NavMenu는 메뉴 역할을 일부러 쓰지 않아요. 여러 그룹이 있는 내비게이션
바 전체가 필요하면 `NavigationMenu` / `gh-navigation-menu`를 사용하세요.

## 구조

`<button aria-expanded aria-controls>` 트리거가 떠 있는 패널을 열고 닫아요. 패널에는 `<a href>` 링크로 이뤄진
일반 목록(`<ul>` / `<li>`)이 들어 있어요. `role="menu"`, `role="menuitem"`, `aria-haspopup="menu"`는 어디에도
없어요. 트리거는 손그림 박스(`@ghds/sketch-core`)이고, 패널은 `comp.menu.*` 토큰을 그대로 써서 Menu와 같은
모양이에요. 데이터 기반 — `{ href, label }` 형태의 `items` 배열을 전달하세요.

## 접근성

- **React / Web Components**: 디스클로저 패턴 — 트리거에 `aria-expanded`와 패널을 가리키는 `aria-controls`가
  있어요. 링크는 자연스러운 Tab 순서에 있어요(로빙 `tabindex` 없음). 화살표 키는 Tab에 더해 쓸 수 있는 보조
  단축키예요. Escape를 누르면 닫히고 포커스가 트리거로 돌아가요. 바깥을 클릭하거나 Tab으로 컴포넌트를 벗어나도
  닫혀요. 링크를 활성화하면 브라우저가 직접 이동해요.
- **React Native**: NavMenu가 없어요 — `@ghds/react-native`의 `NavigationMenu`를 사용하세요.

## 코드 예시

```tsx
// React — @ghds/react
import { NavMenu } from '@ghds/react/nav-menu';

<nav aria-label="Main">
  <NavMenu
    label="Design"
    items={[
      { href: '/design-style/', label: 'Design Style' },
      { href: '/foundations/', label: 'Foundations' },
      { href: '/principles/', label: 'Design Principles' },
      { href: '/ux-writing/', label: 'UX Writing' },
    ]}
  />
</nav>;
```

```html
<!-- Web Components — @ghds/web-components -->
<script type="module">
  import '@ghds/web-components/nav-menu';
  // items는 속성(attribute)이 아니라 프로퍼티예요
  document.getElementById('design').items = [
    { href: '/design-style/', label: 'Design Style' },
    { href: '/foundations/', label: 'Foundations' },
  ];
</script>
<nav aria-label="Main">
  <gh-nav-menu id="design" label="Design"></gh-nav-menu>
</nav>
```
