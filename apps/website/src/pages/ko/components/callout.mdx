## 개요

`Callout`은 문서 페이지, 가이드, 변경 내역 같은 긴 글 안에서 참고, 팁, 주의 사항을 본문과 구분해 보여 주는 박스예요. 사용자의 동작에 대한 반응이 아니라 콘텐츠의 일부라서 정적이에요. 작업이나 페이지의 상태를 알릴 때는 <a href={withBase('/components/alert/')}>Alert</a>를, 일시적인 피드백에는 <a href={withBase('/components/toast/')}>Toast</a>를 사용하세요.

## 구조

변형에 따른 색상 외곽선과 아이콘, 선택적 굵은 제목, 본문을 가진 손그림 스타일의 박스(`@ghds/sketch-core`)예요. 닫기 버튼은 없어요.

## 접근성

- **React와 웹 컴포넌트**: 루트 요소는 `role="note"`예요. 본문에 덧붙이는 내용이라는 뜻이에요. 라이브 리전(`role="status"`/`"alert"`)이 아니므로 스크린 리더가 따로 알리지 않고 문서 순서대로 읽어요.
- 외곽선과 아이콘은 테마별 상태 강조 색(`sys.color.border.*` / `sys.color.icon.*`)을 사용해서 라이트와 다크 테마의 모든 표면에서 3:1 이상을 유지해요. 제목과 본문 텍스트는 4.5:1을 충족해요. 변형 아이콘은 장식용이므로 의미는 제목에 담으세요.
- React: `role` / `aria-label`을 전달해서 기본 역할을 바꾸거나 이름을 붙일 수 있어요.
- 웹 컴포넌트: `<gh-callout>`에 `role` / `aria-label` 속성을 지정하면 `ElementInternals`로 노출되는 기본 역할을 바꾸거나 이름을 붙일 수 있어요.
- <a href={withBase('/accessibility/')}>접근성 가이드</a>를 참고하세요.

## 코드 예시

```tsx
// React — @ghds/react
import { Callout } from '@ghds/react/callout';

<Callout variant="tip" heading="권장 글꼴">
  웹 글꼴은 앱에서 Fontsource로 불러오세요.
</Callout>;
```

```html
<!-- Web Components — @ghds/web-components -->
<script type="module">
  import '@ghds/web-components/callout';
</script>
<gh-callout variant="tip" heading="권장 글꼴">
  웹 글꼴은 앱에서 Fontsource로 불러오세요.
</gh-callout>
```
